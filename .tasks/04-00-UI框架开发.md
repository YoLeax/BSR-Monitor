# 本次目标

搭建应用 UI 框架，包括主布局、导航结构、核心页面骨架，为后续业务功能提供可视化界面基础。

# 具体任务

## 1. 主布局设计

设计整体应用布局：
- 顶部标题栏（应用名称、状态指示）
- 左侧导航栏（玩家、歌单、谱面查询）
- 右侧主内容区（动态显示页面内容）

## 2. 导航结构

实现页面切换逻辑：
- 玩家管理页
- 歌单管理页
- 谱面查询页

暂不引入路由库，使用状态管理实现页面切换。

## 3. 页面骨架组件

创建各页面的基础结构：

### 玩家管理页
- 玩家列表区域（显示已添加的玩家）
- 添加玩家区域（输入框 + 按钮）
- 状态提示区域（加载中、错误信息）

### 歌单管理页
- 歌单列表区域
- 添加歌单区域

### 谱面查询页
- 输入区域（key/hash 输入框）
- 结果展示区域（谱面信息、难度列表）

## 4. 样式方案

使用 CSS 模块化方案：
- `App.css` - 全局样式、布局
- 各组件独立的 CSS 文件

设计原则：
- 简洁实用，暂不做复杂视觉效果
- 预留扩展空间

## 5. 组件目录结构

```
src/
├── components/        # 通用组件
│   ├── Layout/        # 主布局
│   ├── Sidebar/       # 侧边导航
│   └── StatusBox/     # 状态指示
├── pages/             # 页面组件
│   ├── Players/       # 玩家管理页
│   ├── Playlists/     # 歌单管理页
│   └── MapSearch/     # 谱面查询页
└── App.tsx            # 入口组件
```

# 验收标准

- 应用布局清晰，导航可切换页面
- 各页面骨架结构完整
- 样式整洁，视觉效果可接受
- 数据库状态正常显示
- TypeScript 编译无错误
