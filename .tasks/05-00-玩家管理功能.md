# 本次目标

实现玩家管理功能，包括添加玩家、显示玩家列表、拉取成绩、删除玩家。

# 具体任务

## 1. 数据库操作封装

在 `src/db/` 下创建玩家相关的数据库操作函数：

### PlayerInfo 操作
- `addPlayer(player)` - 添加玩家，若已存在则更新
- `getPlayer(id)` - 获取单个玩家
- `getAllPlayers()` - 获取所有玩家列表
- `deletePlayer(id)` - 删除玩家（级联删除成绩）

### PlayerScore 操作
- `addScore(playerId, score, leaderboard)` - 添加单条成绩，处理去重逻辑
- `batchAddScores(playerId, scores)` - 批量添加成绩
- `getPlayerScores(playerId)` - 获取玩家所有成绩
- `getScoreCount(playerId)` - 获取玩家成绩数量

## 2. 玩家管理 UI 功能

### 添加玩家
- 输入玩家 ID，点击添加按钮
- 调用 API 获取玩家信息，存入数据库
- 显示加载状态和错误提示
- 成功后刷新列表

### 玩家列表显示
- 显示已添加的玩家：名称、ID、成绩数量
- 支持删除操作（带确认）
- 空列表时显示提示

### 拉取成绩
- 每个玩家有"拉取成绩"按钮
- 显示拉取进度（已获取数量）
- 成功后更新成绩数量显示

## 3. 组件更新

更新 `src/pages/Players/` 组件：

- 添加状态管理：玩家列表、加载状态、错误信息
- 实现添加玩家逻辑
- 实现拉取成绩逻辑（全量拉取，count=100 循环直到全部获取）
- 实现删除玩家逻辑

## 4. 数据字段映射

参考 [Database.md](../.project/Database.md)：

**PlayerInfo 填充**：
| API 字段 | 表字段 |
|----------|--------|
| `id` | `id` |
| `name` | `name` |
| `avatar` | `avatarURL` |

**PlayerScore 填充**：
| API 字段 | 表字段 |
|----------|--------|
| `score.id` | `scoreId` |
| `leaderboard.id` | `leaderboardId` |
| `leaderboard.songHash` | `hash` |
| `leaderboard.modeName` | `mode` |
| 难度值转换 | `difficulty` |
| `score.accuracy` | `accuracy` |
| `score.epochTime` | `epochTime` |

**去重逻辑**：复合主键 `(playerId, hash, mode, difficulty)`，新成绩时间戳更大时更新。
