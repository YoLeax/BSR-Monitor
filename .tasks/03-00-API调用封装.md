# 本次目标

封装 BeatLeader 和 BeatSaver API 调用，为后续玩家管理、谱面查询、歌单管理等业务功能提供基础。

# 具体任务

## 1. API 配置与工具

- 创建 API 配置文件（baseUrl、timeout 等）
- 实现通用请求工具（错误处理、响应解析）

## 2. BeatLeader API 封装

实现以下接口：

| 函数 | API | 用途 |
|------|-----|------|
| `getPlayerInfo(id)` | GET `/player/{id}` | 获取玩家基本信息 |
| `getPlayerScores(id, count)` | POST `/player/{id}/scores/compact` | 拉取玩家成绩 |
| `getLeaderboard(id)` | GET `/leaderboard/{id}` | 获取排行榜详情 |

## 3. BeatSaver API 封装

实现以下接口：

| 函数 | API | 用途 |
|------|-----|------|
| `getMapByKey(key)` | GET `/maps/id/{key}` | 通过 key 获取谱面信息 |
| `getMapByHash(hash)` | GET `/maps/hash/{hash}` | 通过 hash 获取谱面信息 |
| `getPlaylist(id, page)` | GET `/playlists/id/{id}/{page}` | 获取歌单详情 |

## 4. leaderboardId 解析工具

实现解析函数，从 leaderboardId 提取 key、难度、模式：

```
输入: "4b302xx91"
输出: { key: "4b302", difficulty: "ExpertPlus", mode: "Standard" }
```

解析规则见 [.project/Project.md](../.project/Project.md)。

## 5. 类型定义

为 API 响应创建 TypeScript 类型定义，便于后续开发。

# 验收标准

- 所有 API 函数可正常调用并返回数据
- leaderboardId 解析正确（测试多种格式）
- 类型定义完整
- 模块导出清晰（`src/api/index.ts`）

# 任务总结

## 已完成的工作

1. **API 配置** - [config.ts](src/api/config.ts)
   - BeatLeader 和 BeatSaver baseUrl 配置
   - 默认 timeout 30秒

2. **通用请求工具** - [request.ts](src/api/request.ts)
   - 封装 fetch 请求，支持 GET/POST
   - 实现 timeout 控制（AbortController）
   - 自定义 `APIError` 错误类，包含 status、message、url

3. **类型定义** - [types.ts](src/api/types.ts)
   - BeatLeader: `BLPlayerResponse`, `BLCompactScoreResponseWithMetadata`, `BLLeaderboardResponse`
   - BeatSaver: `BSMapDetail`, `BSPlaylistPage` 及相关嵌套类型
   - 难度/模式映射常量：`BL_DIFFICULTY_MAP`, `BL_MODE_MAP`

4. **BeatLeader API** - [beatleader.ts](src/api/beatleader.ts)
   - `getPlayerInfo(id)` - GET `/player/{id}`
   - `getPlayerScores(id, count)` - POST `/player/{id}/scores/compact`
   - `getLeaderboard(id)` - GET `/leaderboard/{id}`

5. **BeatSaver API** - [beatsaver.ts](src/api/beatsaver.ts)
   - `getMapByKey(key)` - GET `/maps/id/{key}`
   - `getMapByHash(hash)` - GET `/maps/hash/{hash}`
   - `getPlaylist(id, page)` - GET `/playlists/id/{id}/{page}`

6. **leaderboardId 解析** - [leaderboardId.ts](src/api/leaderboardId.ts)
   - `parseLeaderboardId(id)` - 解析 BL leaderboardId，返回 key、difficulty、mode
   - `isValidLeaderboardId(id)` - 验证格式有效性
   - 支持版本段（x/xx）和无版本段两种情况
   - 测试用例全部通过

7. **模块导出** - [index.ts](src/api/index.ts)
   - 统一导出所有 API 函数、类型定义、工具函数
